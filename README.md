# Python-ATM
A python ATM system featuring JSON Data persistence.

The code does:
  1. Creates multiple accounts for different users
  2. Has a built in PIN system
  3. Can check balance, add deposit, and withdraw money
  4. Also saves and loads the file so the data is not overwritten
